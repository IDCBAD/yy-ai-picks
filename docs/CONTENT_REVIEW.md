# 内容审核清单

## 公开展示规则

- 只公开 `publishStatus: "published"` 的推荐。
- `editorialStatus: "needs-review"` 不显示“已验证”“长期实测”等结论。
- 推荐详情可以展示中性的收录说明、分类、标签、平台和关联内容。
- 统一占位的 `usageDescription` 在完成个人核验前不公开展示。
- 不为了填满首页或详情页修改使用关系、关联或推荐理由。

## 通用待核对字段

| 字段                            | 当前内容                             | 建议核对动作                                 |
| ------------------------------- | ------------------------------------ | -------------------------------------------- |
| `recommendationReason`          | 根据原型资料整理的中性收录说明       | 确认是否确有个人判断；没有则继续使用中性措辞 |
| `usageDescription`              | “原型未提供具体个人使用方式”统一占位 | 补充真实工作流，或保持不公开                 |
| `suitableFor` / `unsuitableFor` | 统一评估边界                         | 按产品实际能力和个人经验逐条核对             |
| `strengths` / `limitations`     | 简介复述与统一风险提示               | 补充可验证优缺点，删除重复说明               |
| `pricing` / `accessRegion`      | 种子数据或缺失                       | 对照官网复查当前套餐和可用地区               |
| `lastCheckedAt`                 | 统一检查日期                         | 实际复查官网后更新                           |

## Phase 5 公开页面处理

- 6 个场景的步骤、首选、替代和 `selectionReason` 来自现有种子资料，页面明确提示需结合实际需求复核，不表述为已经验证的个人工作流。
- 分类和场景当前没有可靠关联文章，相关文章区块按数据隐藏，不为了填满页面引用无关内容。
- 4 条 ArticleReference 均为有效官方文档，只作为搜索结果或真实关联引用，不表述为个人文章。
- 4 个项目均缺少公开项目地址和开发记录地址，项目页隐藏相应按钮，不使用 `#`、提示框或回到当前页的伪详情入口。
- “关于”页只说明网站目标、收录规则、审核方式与免责声明；未加入“不接广告”“生产验证”等未经确认的个人声明。
