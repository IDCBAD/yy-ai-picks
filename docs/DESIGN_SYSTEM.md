# 设计系统

## 设计方向

视觉延续 Open Design 的个人编辑手册与轻微剪贴簿感：暖白纸张、白色内容面、深色粗描边、黄色重点、硬阴影和克制旋转。整体应可读、明确、有个人判断，不改成紫色渐变、玻璃拟态、普通 SaaS 模板或复杂 3D 风格。

## 原型共性

- 七个页面共享固定宽度容器、顶栏、移动菜单、面包屑、章节标题、胶囊标签、描边卡片、页脚和返回顶部。
- 首页以 Hero 后接多组网格；分类页以标签筛选控制推荐列表；场景页在桌面使用横向步骤线、移动端改为纵向；详情页使用编号章节；搜索页按内容类型分组；项目页按状态分组；关于页解释推荐标准。
- 原型中的页面内样式、内联色值、重复卡片和字符串 SVG 不是正式实现方式，Phase 3 应归并到令牌和共享组件。

## 颜色令牌

| Token                | 值        | 用途                   |
| -------------------- | --------- | ---------------------- |
| `--color-background` | `#FFF8EC` | 页面纸张背景           |
| `--color-surface`    | `#FFFFFF` | 卡片、输入框、浮层     |
| `--color-foreground` | `#1A1A1A` | 主文字、粗边框、硬阴影 |
| `--color-muted`      | `#6B6357` | 辅助文字与次级信息     |
| `--color-border`     | `#E0D8C8` | 柔和分隔线与非重点边框 |
| `--color-accent`     | `#E8C547` | 重点、选中、主操作     |
| `--color-accent-ink` | `#8A7300` | 大字号辅助强调文字     |

状态色必须通过统一映射使用，并验证与背景的对比度。黄色按钮、筛选项和徽标使用 `--color-foreground`，不使用对比度不足的 `--color-accent-ink` 作为普通字号文字。页面不得散落重复十六进制颜色。

## 字体规则

- 展示文字：优先采用具有圆润、编辑感的无衬线字体；原型声明 `cereal`，若无可合法分发的字体文件则使用系统无衬线回退，不依赖运行时远程字体。
- 正文与界面：系统无衬线字体，中文回退到 `PingFang SC`、`Microsoft YaHei`、`Source Han Sans SC`、`Noto Sans SC`。
- 编号、日期、状态和短标签：JetBrains Mono 或系统等宽字体。
- 正文保持舒适行高，中文段落不使用过窄字宽或过密字距。

## 字号层级

| 层级    | 桌面建议 | 移动建议 | 用途                  |
| ------- | -------- | -------- | --------------------- |
| Display | 56–64px  | 38–44px  | 仅首页或重要页面 Hero |
| H1      | 44–52px  | 34–40px  | 页面标题              |
| H2      | 28–36px  | 24–30px  | 主章节标题            |
| H3      | 18–22px  | 18–20px  | 卡片或小节标题        |
| Body    | 16–18px  | 16px     | 正文                  |
| Small   | 13–14px  | 13–14px  | 元数据和辅助说明      |

字号不随视口连续缩放，按断点切换；紧凑组件不使用 Hero 级字号。

## 间距系统

以 8px 为基准：`4、8、12、16、24、32、40、48、64、80、96`。组件内部优先使用 8–24px，章节使用 48–96px。固定格式的卡片、工具栏和图标按钮使用稳定尺寸，动态内容不能引起明显跳动。

内容最大宽度为 1360px；长文章与详情正文使用更窄的阅读宽度。

## 圆角、边框与阴影

- 大卡片圆角：24px；小控件圆角：12px；胶囊标签：9999px。
- 主描边：2.5px `#1A1A1A`；次级分隔：1px `#E0D8C8`。
- 硬阴影：`4px 4px 0 #1A1A1A`。
- 柔阴影：`8px 8px 16px rgba(26, 26, 26, 0.08)`。
- 组合阴影只用于主要卡片与浮层，不能让每个区块都像浮动卡片。
- Hover 可增加到约 `6px 6px` 的硬阴影并轻微位移；不得改变元素占位尺寸。

## 按钮

- 主按钮：黄色背景、深色粗边框、硬阴影，使用清晰命令文字或图标加文字。
- 次按钮：白色或暖白背景、深色边框。
- 图标操作优先使用熟悉图标并提供 tooltip 与 `aria-label`。
- 最小点击区域 44×44px；按下时只做轻微位移和阴影变化。
- 禁用态仍需可辨识，不只依赖颜色。

## 标签与状态

- 分类、筛选和短标签使用胶囊外形；选中态以黄色填充和深色描边表示。
- 推荐关系状态由一份映射统一给出中文、颜色和图标。
- 标签支持键盘焦点；移动端横向滚动时保留可见滚动提示，不造成页面横向溢出。

## 卡片

- 卡片是重复内容项，不用于包裹整段页面区块，也不嵌套装饰性卡片。
- 推荐、分类、场景、项目和文章各有一套核心组件，可通过少量 `variant` 调整密度。
- 旋转只用于少数编辑感卡片，角度应固定且小于 1°；移动端和 reduced motion 环境关闭旋转。
- Hover 不承载关键内容，卡片标题、状态和主要操作始终可见。

## 导航栏

- 桌面显示品牌、主导航和搜索入口；移动端折叠为菜单按钮。
- 当前页面状态明确；导航和菜单全键盘可用。
- 移动菜单按钮提供 `aria-expanded`，打开后管理焦点与 Escape 关闭。
- 导航高度稳定，内容变化不引起页面跳动。

## 响应式断点

| 断点          | 规则                                   |
| ------------- | -------------------------------------- |
| 1440px 及以上 | 最大宽度容器，推荐网格 3–4 列          |
| 1024px        | 平板与小桌面，网格 2–3 列              |
| 768px         | 移动布局入口，导航折叠、网格单列或双列 |
| 390px         | 小屏验收宽度，单列、无横向页面溢出     |

详情双栏在移动端改为上下布局；场景流程改为纵向时间线；筛选改为抽屉；标签允许局部横向滚动。

## Hover、Focus 与动效

- 可点击元素 Hover 使用轻微上移、阴影或颜色变化，持续 150–300ms。
- `focus-visible` 使用黄色 3px 外环加深色 5px 外环，任何背景上都清晰。
- 动效只帮助理解层级和反馈，不用于持续装饰。
- `prefers-reduced-motion: reduce` 下关闭平滑滚动、旋转、位移和非必要过渡。

## 原型修正规则

- 把页面内重复样式和内联值收敛为令牌和共享组件。
- 把字符串拼接与 `innerHTML` 渲染替换为 React 组件，避免不安全内容注入。
- 把页面级 DOM 查询筛选替换为数据服务和 URL 状态。
- 把 `category.html`、`scenario.html`、`detail.html` 的查询参数导航替换为语义化 slug 路由。
- 统一原型中不一致的卡片、状态文字、图标来源和空状态。
- 对字体授权、外部链接、缺失文章链接、动态内容转义和移动菜单焦点进行正式检查。

## Phase 3 实现

- 全部颜色、字号、行高、间距、圆角、边框、阴影、焦点、动效、内容宽度和层级令牌统一定义于 `src/app/globals.css`。
- 页面使用 `PageContainer` 控制最大宽度和响应式边距；页面区块保持无外层卡片。
- `Button`、`Tag`、`Badge`、`IconButton`、`Card` 与 `ExternalLink` 是基础控件，不按页面复制样式。
- `RecommendationCard` 只有 `default`、`compact`、`featured` 三种密度，移动端与 reduced motion 下取消装饰旋转。
- `StatusBadge` 的六种推荐关系由 `RECOMMENDATION_STATUS` 一处映射文字、色调和 Lucide 图标。
- 图标只使用 `lucide-react`；装饰图标隐藏于辅助技术，图标按钮必须有可访问名称。
- `/dev/components` 是内部组件预览，设置 `noindex`，不加入正式导航，也不承担业务页面职责。

## Phase 5 页面规则

- 分类页推荐网格固定为桌面三列、平板两列、移动单列；标签只在自身滚动容器内横向滚动。
- 场景流程在所有宽度使用清晰编号和纵向阅读顺序，不复制原型的桌面横向时间线；移动端工具组继续纵向排列。
- 搜索结果按内容类型分成独立章节，推荐继续复用 RecommendationCard，场景、项目和文章使用统一 SearchResultCard。
- 项目状态分组是无外层卡片的页面章节；无项目的状态不显示空装饰区块。
- 关于页使用窄阅读宽度和编号章节，收录与排除标准在桌面双列、移动端单列。
