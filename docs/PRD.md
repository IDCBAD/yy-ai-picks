# 产品需求文档

## 项目背景

“余一的 AI 推荐清单”用于整理作者在 AI 编程、Agent 开发、自动化、知识管理和内容创作中真实使用、认真体验或持续关注的工具、产品与资源。Open Design 原型提供视觉、布局、交互和内容结构参考，正式项目不沿用其逐页脚本和大对象数据组织方式。

## 产品定位

这是带有个人判断和使用经验的精选清单，不是追求收录数量的导航站、排行榜、官网介绍集合或自动采集目录。每条推荐应回答：它是什么、为什么推荐、适合解决什么问题、适合谁、作者如何使用、有哪些限制、有哪些替代，以及能与哪些工具组成工作流。

## 目标用户

- 正在选择 AI 工具，希望看到真实经验而非宣传材料的人。
- 需要为具体工作场景组合工具和流程的开发者、创作者与独立产品制作者。
- 希望比较工具适用对象、限制、价格、平台和部署方式的人。
- 关注作者项目、方法和长期工具变化的读者。

## 用户核心任务

1. 从首页快速理解清单的判断标准并发现近期更新。
2. 按分类或使用场景浏览推荐。
3. 阅读单项推荐的理由、用法、优点、限制和替代方案。
4. 搜索工具、场景、项目和文章，并通过筛选缩小范围。
5. 了解作者自己的项目和推荐标准。

## 页面清单

| 路由                      | 页面职责                                                         | Open Design 参考 |
| ------------------------- | ---------------------------------------------------------------- | ---------------- |
| `/`                       | 首页：Hero、搜索、最近更新、场景、分类、长期使用、全部推荐、项目 | `index.html`     |
| `/categories/[slug]`      | 分类信息、子标签筛选、推荐列表、相关场景和文章                   | `category.html`  |
| `/scenarios/[slug]`       | 场景介绍、适用人群、步骤化流程、工具汇总和相关文章               | `scenario.html`  |
| `/recommendations/[slug]` | 推荐详情、使用方式、适用对象、优缺点、替代项和更新记录           | `detail.html`    |
| `/search`                 | 按类型分组展示搜索结果和无结果状态                               | `search.html`    |
| `/projects`               | 按项目状态分组展示作者项目                                       | `projects.html`  |

原型中的 `.html` 文件名和查询参数仅作为参考，不保留为正式路由。

## 功能范围

- 数据驱动的推荐、分类、标签、场景、项目和文章引用。
- 统一的推荐关系状态、项目状态、定价和发布状态。
- 分类浏览、场景工作流、推荐详情、项目分组与关于说明。
- 本地全文搜索和多条件筛选，状态同步到 URL。
- 真正的 404、加载、错误和空状态。
- SEO 元数据、sitemap、robots.txt 和基础结构化数据。
- 键盘操作、清晰焦点、可读对比度、44px 最小点击区域和 reduced motion。
- 1440px、1024px、768px、390px 重点宽度适配。

## 当前版本不做

管理后台、注册登录、收藏同步、评论、排行榜、会员、投稿审核、多角色权限、实时协作、第三方工具自动抓取、推荐理由自动生成和复杂数据统计均不在当前版本范围内。

## 用户浏览路径

- 首页 → 分类 → 推荐详情 → 外部官网或同类替代。
- 首页 → 使用场景 → 分步工作流 → 推荐详情。
- 任意页 → 搜索 → 分组结果 → 推荐、场景、项目或文章。
- 首页或导航 → 我的项目 → 项目状态分组。
- 任意页 → 关于 → 推荐标准、状态含义和更新机制。

无效分类、场景或推荐 slug 必须进入 404；外部链接在新窗口打开时必须带安全属性。

## 搜索和筛选规则

搜索匹配名称、域名、简介、分类、标签、推荐理由、使用场景、项目和文章。结果分为推荐工具、场景清单、我的项目、文章引用四组；显示总数和各组数量。

筛选支持分类、使用关系、定价、是否开源、是否自托管和平台。关键词与筛选值写入 URL Search Params，刷新后保持，支持单项移除和全部清空。搜索和筛选由集中服务处理，不通过页面 DOM 查询拼装结果。

## 推荐标准

- 作者实际使用、在项目中验证、认真体验或持续观察过。
- 能明确说明价值、适用对象、使用场景和局限。
- 优先收录能改善工作流、提供独特能力或启发产品判断的项目。
- 热度、广告、官网宣传和同质化本身不构成收录理由。
- 推荐状态随持续使用和复查结果变化；失效、停更或判断变化时更新或归档。

## 本轮范围

本轮仅完成 Phase 0 与 Phase 1：分析、文档、项目骨架、全局布局及质量工具。不会创建上述业务路由、业务数据、Repository、Service 或业务组件。
